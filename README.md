# Lumi

> 보고, 묻고, 듣는 Ray-Ban Meta 개인 AI 비서

Lumi는 Ray-Ban Meta 안경과 iPhone을 연결해 음성·카메라·현재 위치를 일상적인 대화에 활용하는 개인 AI 비서입니다. 안경에 대고 질문하면 답을 듣고, 눈앞의 장면을 설명받고, 필요한 정보는 사용자 메모리와 일정으로 남길 수 있습니다.

현재 저장소는 실기기 연결과 핵심 경험을 검증하기 위한 iOS MVP입니다. Lumi는 Meta 또는 Ray-Ban의 공식 제품이나 제휴 서비스가 아닙니다.

## 핵심 경험

Lumi는 안경을 단순한 카메라가 아니라, 일상에서 바로 말을 걸 수 있는 개인 비서의 입·귀·눈으로 사용합니다.

1. **묻기** — 안경 또는 현재 연결된 오디오 기기로 자연스럽게 질문합니다.
2. **보기** — 장면을 설명하거나 읽을 수 있는 텍스트를 번역해야 할 때만 안경 카메라로 한 장을 촬영합니다.
3. **기억하기** — 명시적으로 요청한 정보에 기록 시각과 장소를 덧붙여 저장하고, 나중에 대화로 다시 꺼냅니다.

예를 들어 “어제 부산에서 기록한 메모가 뭐였지?”라고 물으면 Lumi는 저장 시각, 기록 장소, 메모리 분류를 함께 비교해 관련 기록만 짧게 답합니다.

## Lumi로 할 수 있는 일

| 기능 | 경험 |
| --- | --- |
| 음성 대화 | 안경 마이크·스피커를 우선 사용해 자연스럽게 질문하고 답을 듣습니다. 답변 중 마이크를 누르면 재생을 멈추고 바로 다음 질문을 시작합니다. 안경을 쓸 수 없으면 iPhone 또는 현재 연결된 Bluetooth 오디오 기기로 이어서 대화합니다. |
| 키보드 입력 (실험) | 설정에서 켜면 안경 마이크 없이 iPhone 키보드로 현재 대화에 질문을 보낼 수 있습니다. 음성 질문과 같은 AI 의도 분석과 대화 맥락을 사용합니다. |
| 장면 이해 | 안경 카메라로 사진 한 장을 촬영해 메뉴, 문서, 물건, 주변 장면을 설명받습니다. |
| 카메라 번역 | 안경 카메라로 촬영한 메뉴·문서 등의 읽을 수 있는 텍스트를 한국어로 번역합니다. |
| 사용자 메모리 | “기억해줘”, “메모해줘”, “기록해줘”처럼 명확히 요청한 내용만 요약·기록 시각·현재 위치와 함께 저장합니다. 대화로 찾은 메모리는 답변 아래 카드로 확인하고 수정·삭제할 수 있습니다. |
| 장소 기억 | “여기 기억해줘”라고 말하면 위치·사진·메모·검색 태그를 함께 남기고 Apple 지도 길찾기로 이어갑니다. |
| 주차 기억 | 현재 주차 위치를 요청하면 안경 사진과 위치를 함께 저장하며, 가장 최근 기록 하나만 유지합니다. |
| 일정과 리마인더 | 대화에서 약속 시각을 파악해 Lumi 일정으로 등록하고, 지정한 시간에 로컬 알림을 보냅니다. |
| 타이머 | “파스타 8분 타이머 맞춰줘”처럼 말하면 남은 시간을 보여주고 완료 알림을 보냅니다. 앱을 나가도 잠금 화면과 다이나믹 아일랜드에서 확인할 수 있습니다. |
| 날씨 | 현재 위치를 기준으로 기상청 단기예보를 조회해 오늘·내일·특정 시간대의 날씨를 안내합니다. |

### 안경 없이도 가능한 범위

| 경험 | Ray-Ban Meta 필요 여부 | iPhone 또는 Bluetooth 오디오 폴백 |
| --- | --- | --- |
| 음성 질문·음성 답변 | 선택 | 가능 |
| 키보드 질문 | 불필요 | 해당 없음 |
| 시간·날씨·메모리·일정·타이머 | 불필요 | 가능 |
| 장면 설명·카메라 번역 | 필요 | 불가 |
| 사진을 포함한 장소·주차 기억 | 필요 | 불가 |

음성 입력과 답변은 Ray-Ban Meta 핸즈프리 오디오를 먼저 선택합니다. 사용할 수 없으면 다른 Bluetooth 핸즈프리 기기, 그다음 iPhone 내장 마이크·스피커 순으로 동작합니다. 설정의 **오디오 기기 상태**에서 실제 사용 중인 마이크와 스피커를 각각 확인할 수 있습니다.

## 이렇게 사용하세요

1. iPhone에서 Lumi를 열고 Ray-Ban Meta 안경을 연결합니다. 안경이 없어도 음성 대화는 iPhone 또는 Bluetooth 오디오 기기로 사용할 수 있습니다.
2. 메인 화면에서 안경 상태, 진행 중인 타이머, 다가오는 일정을 확인합니다.
3. AI 제어에서 장면 촬영, 음성 질문, 카메라 번역 또는 장소 저장을 바로 시작합니다.
4. 설정에서 **실행 전 확인**을 켜면, 일정·타이머·장소·주차·사용자 메모리 저장 전에 실행 여부를 확인합니다. **키보드 입력 (실험)**을 켜면 AI 제어에 텍스트 입력창이 나타납니다.
5. 답변은 음성으로 듣고, 대화와 사진은 해당 대화 세션에서 다시 확인합니다. 답변 도중 새 질문이 생기면 마이크 버튼의 **말 끊고 질문**을 눌러 즉시 이어서 말할 수 있습니다.
6. 정말 남겨야 할 정보는 “기억해줘”라고 말해 사용자 메모리에 저장합니다.

- “그 기억을 수정해줘. 이제 라테를 마셔.”

## 메모리의 저장·검색 기준

Lumi는 “기억해줘”, “메모해줘”, “기록해줘”를 같은 저장 의도로 해석하지만, 단어만 나왔다고 모든 대화를 저장하지는 않습니다. 저장할 대상이 명확할 때만 핵심 내용을 짧게 추출합니다.

| 요청 | 저장 또는 실행 결과 |
| --- | --- |
| “다음 주에 디자인 검토하기 기억해줘” | 일반 사용자 메모리로 내용·기록 시각·현재 위치 저장 |
| “내일 3시에 팀 회의 기억해줘” | 사용자 메모리가 아닌 Lumi 일정과 로컬 알림 등록 |
| “여기 기억해줘” | 장소 메모리에 안경 사진·현재 위치·기록 시각 저장 |
| “여기 주차했어 기록해줘” | 주차 메모리에 사진·위치·기록 시각 저장, 이전 주차 기억 교체 |
| “어제 부산에서 기록한 메모” | 기록 시각과 저장 장소를 함께 비교해 관련 메모리 검색 |
| “그 커피 취향 메모를 수정해줘” | 하나의 메모리가 확실할 때만 내용 수정. 사진·장소·기록 시각은 유지 |

위치 권한을 허용하지 않은 경우에도 일반 메모리와 일정은 저장되지만 장소는 비어 있을 수 있습니다. 과거 기록의 위치를 나중에 추정해 채우지 않습니다.

## 앱 구성

### Lumi

안경 연결 상태와 모델 이미지를 중심으로, 현재 실행 중인 타이머·다가오는 일정을 한눈에 보여줍니다. 메인 화면은 정보를 과하게 카드로 나누지 않고 하나의 밝은 캔버스 위에 자연스럽게 배치합니다.

### 오디오 기기 선택

음성 질문과 답변은 Ray-Ban Meta의 Bluetooth 핸즈프리 오디오를 우선 사용합니다. 안경 오디오를 사용할 수 없으면 iOS의 현재 오디오 경로를 따르므로, 연결된 Bluetooth 핸즈프리 기기 또는 iPhone 내장 마이크·스피커로 계속 대화할 수 있습니다. 카메라 촬영·장면 이해·장소 저장은 Ray-Ban Meta 연결이 필요합니다.

설정의 **오디오 기기 상태**에서 Lumi가 현재 사용할 마이크와 스피커를 각각 확인할 수 있으며, 안경·Bluetooth 기기 연결 또는 해제 시 자동으로 갱신됩니다.

### 대화

새 세션을 만들기 전까지 한 대화를 계속 이어갑니다. 세션별 생성 시각과 대화 내용을 보관하며, 사진으로 질문한 경우 촬영 이미지도 대화 속에서 함께 확인할 수 있습니다.

### 사용자 메모리

일반, 일정, 주차, 장소 카테고리로 정보를 관리합니다. 새 사용자 메모리와 새 일정에는 기록 시각과 iPhone의 현재 위치를 함께 저장합니다. 위치 권한이 없었던 기존 기록은 당시 위치를 알 수 없으므로 그대로 보존합니다.

일정 카테고리는 별도 메모를 복제하지 않고 **실제 Lumi 일정과 같은 항목**을 보여줍니다. 일정 탭 또는 사용자 메모리의 일정 필터 어디에서 수정·삭제해도 일정 시각, 메모, 로컬 알림이 함께 반영됩니다. 일반·주차·장소 메모리는 직접 추가·수정·삭제하거나 한 번에 비울 수 있으며, 주차 기억은 가장 최근 기록 하나만 유지합니다.

검색창에서는 제목·내용·카테고리·저장 장소·태그·사진 설명을 함께 찾을 수 있습니다. 대화 중에는 저장된 메모리의 제목·내용·기록 시각·기록 장소·태그·사진 설명을 참고해 날짜와 장소를 조합한 질문을 처리합니다. 답변에 실제로 사용한 일반·장소·주차 메모리는 제목, 날짜, 장소, 사진, 태그가 담긴 카드로 메인 답변과 대화 기록에 남습니다. 메모리를 나중에 삭제하면 기존 답변 텍스트는 유지되고 해당 카드만 숨겨집니다.

메모리 화면 상단의 **목록 / 사진** 전환으로 사진이 있는 메모리만 2열 갤러리에서 볼 수 있습니다. 새로 저장하는 장소·주차·사진 메모리는 Gemini가 검색용 사진 설명과 태그를 자동 생성합니다. 기존 사진은 자동으로 보내지 않으며, 사진 화면의 **기존 사진 분석**을 누르고 전송 안내를 확인한 경우에만 색인되지 않은 사진을 순서대로 분석합니다. 실패한 항목은 같은 화면에서 다시 시도할 수 있습니다.

장소 이름과 태그는 저장 시 Gemini가 제안하지만 메모리 편집 화면에서 직접 고칠 수 있습니다. 태그는 공백과 중복을 정리해 최대 8개까지 저장합니다. 수정 요청은 대상이 하나로 확실할 때만 실행하며, 수정해도 사진·위치·기록 시각은 유지됩니다. 삭제하면 연결된 사진·위치 정보도 함께 제거됩니다.

장소·주차 기억에는 메모리 화면에서 지도와 현재 위치로부터의 거리를 표시합니다. 거리 확인을 누르면 iPhone의 현재 위치 권한을 요청하며, `지도에서 열기`로 위치를 확인하거나 `길찾기`로 Apple 지도의 목적지 경로 화면을 열 수 있습니다.

### 주차 기억

주차 위치를 잊기 쉬운 상황을 위한 단일 최신 기록 기능입니다.

1. 안경을 착용한 상태에서 “여기 주차했어 기억해줘” 또는 “주차한 곳 기록해줘”라고 말합니다.
2. Lumi가 안경 카메라로 현재 장면을 촬영하고 iPhone의 현재 위치를 가져옵니다.
3. **사용자 메모리 → 주차 기억**에서 촬영 사진, 저장 시각, 주소 또는 좌표를 확인합니다.
4. `지도에서 열기`를 누르면 Apple 지도에서 저장 위치를 확인할 수 있습니다.

새 주차 기억을 저장하면 이전 주차 메모리와 사용자 메모리에 연결된 사진은 자동으로 제거되어, 사용자 메모리에는 최신 항목 하나만 남습니다. 음성 요청이 포함된 대화 세션 기록은 별도로 남을 수 있습니다. 주차 위치를 직접 수정하거나 삭제할 수도 있습니다. 위치 권한 또는 안경 카메라에 접근할 수 없으면 주차 기억을 완성할 수 없습니다.

### 일정

대화로 등록된 일정과 수동으로 만든 일정을 확인·수정·삭제합니다. 일정은 사용자 메모리의 **일정** 필터에도 같은 항목으로 표시되며, 두 화면은 하나의 일정 데이터를 공유합니다. 알림 권한이 허용된 경우 iPhone 로컬 알림으로 알려드립니다.

### 설정

상단 설정에서 **실행 전 확인**을 켜거나 끌 수 있습니다. 기본값은 켜짐이며, 켜진 경우 Lumi는 아래 동작을 실행하기 전에 요약 내용을 보여주고 실행 여부를 묻습니다.

- 사용자 메모리 저장
- 사용자 메모리 수정
- 사용자 메모리 삭제
- 장소·주차 기억 저장
- 일정 등록
- 타이머 시작

직접 입력 화면에서 저장하는 일정·메모리는 사용자가 이미 내용을 검토한 뒤 저장하므로, 별도 확인을 추가하지 않습니다.

**키보드 입력 (실험)**을 켜면 메인 화면의 AI 제어에 입력창이 표시됩니다. 안경 마이크를 열지 않아도 현재 대화 세션의 맥락을 유지한 채 질문을 보낼 수 있으며, 답변·일정·타이머·메모리 요청은 음성 질문과 동일한 흐름으로 처리합니다. 장면 촬영이나 장소·주차 저장처럼 안경 카메라가 필요한 요청은 안경 연결이 필요합니다.

### 답변 상태와 음향 효과

질문을 보낸 뒤의 녹음·처리·답변 재생 상태는 상단 다이나믹 아일랜드 형태의 상태 카드에서 애니메이션으로 확인합니다. 상태 문구가 화면에 계속 쌓이지 않도록 하고, 마이크 시작·종료와 답변 대기 시점에는 짧은 효과음으로 전환을 알립니다. 답변 재생 중 마이크 버튼을 누르면 음성을 즉시 중단하고 새 질문 녹음을 시작하며, 중단된 답변 텍스트와 대화 기록은 그대로 남습니다.

### Live Activity 타이머

타이머를 시작하면 Lumi가 잠금 화면에 남은 시간을 표시합니다. 다이나믹 아일랜드를 지원하는 iPhone에서는 상단에도 축약된 카운트다운이 나타나며, 길게 누르면 타이머 이름과 제어 버튼을 확인할 수 있습니다.

- **일시정지 / 재개:** Live Activity의 버튼을 누르면 Lumi를 열어 타이머 상태를 반영합니다.
- **취소:** Live Activity 또는 앱 안의 취소 버튼으로 타이머와 예정된 알림을 함께 제거합니다.
- **여러 타이머:** 잠금 화면에는 여러 활동이 표시될 수 있지만, 다이나믹 아일랜드에는 iOS가 선택한 활동이 표시됩니다.

Live Activity 표시는 iOS 시스템 설정, 집중 모드, 기기 지원 여부에 따라 제한될 수 있습니다.

## 개인정보와 데이터

Lumi는 개인 정보가 필요한 순간을 가능한 한 분명하게 드러내는 것을 원칙으로 합니다.

- 대화 세션, 사용자 메모리, 일정, 타이머는 iPhone 앱의 로컬 저장소에 보관합니다.
- 장면 질문을 하거나 새 사진 메모리의 검색 색인을 만들 때 촬영한 사진을 Gemini API에 보내 분석합니다. 해당 사진은 대화 기록 또는 사용자 메모리에 남길 수 있습니다.
- 새 사용자 메모리와 일정의 기록 시각·현재 위치, 그리고 장소·주차 기억을 위해 촬영한 사진은 iPhone 로컬에 보관합니다. 장소·주차 사진은 저장 시 장소 이름·태그·사진 설명을 제안받기 위해 Gemini 분석 요청에 포함될 수 있습니다.
- 기존 메모리 사진은 자동 분석하지 않습니다. 사용자가 사진 갤러리에서 전송 안내를 확인하고 **기존 사진 분석**을 실행한 경우에만 Gemini API에 순차 전송합니다. 대화 기록에만 있고 사용자 메모리로 저장하지 않은 사진은 갤러리와 사진 검색 색인에서 제외합니다.
- 음성 질문의 처리를 위해 녹음 데이터와 대화 맥락이 Gemini API 요청에 포함될 수 있습니다.
- 날씨 요청 시 현재 위치를 기상청 예보 격자로 변환해 조회합니다.
- 앱 설정에서 불필요한 사용자 메모리·일정·타이머를 삭제할 수 있습니다.

민감한 개인정보, 인증 정보, 타인의 얼굴이나 문서가 담긴 이미지는 충분히 확인한 뒤 사용하세요. 실제 서비스 출시 전에는 별도 개인정보 처리방침, 동의 흐름, 데이터 보존 정책 및 서버 보안 설계가 필요합니다.

## 기술 구성

- **UI:** SwiftUI
- **웨어러블 연결:** Meta Wearables Device Access Toolkit (`MWDATCore`, `MWDATCamera`)
- **AI:** Gemini API
  - `gemini-3.1-flash-lite` — 대화, 의도 파악, 장면 분석
  - `gemini-3.1-flash-tts-preview` — 한국어 음성 답변 생성
- **날씨:** 기상청 단기예보 조회서비스
- **알림:** UserNotifications 로컬 알림
- **Live Activity:** ActivityKit · WidgetKit

## 시작하기

### 요구 사항

- Xcode에서 현재 프로젝트의 배포 대상인 iOS 26.5 이상을 실행할 수 있는 iPhone
- Ray-Ban Meta 안경 및 Meta AI 앱 연결
- Meta Wearables Developer Mode 설정
- Gemini API 키
- 기상청 공공데이터포털 단기예보 API 인증키

### 1. 비밀 설정 만들기

저장소 루트에서 예시 파일을 복사합니다.

```bash
cp Secrets.xcconfig.example Secrets.xcconfig
```

`Secrets.xcconfig`에 본인 값만 입력합니다.

```xcconfig
META_APP_ID = 0
META_CLIENT_TOKEN = YOUR_META_CLIENT_TOKEN
GEMINI_API_KEY = YOUR_GEMINI_API_KEY
KMA_WEATHER_API_KEY = YOUR_KMA_WEATHER_API_KEY
```

개발 모드에서는 `META_APP_ID`를 `0`으로 둘 수 있습니다. 실제 배포 환경에서는 Meta 앱 ID와 클라이언트 토큰을 올바르게 설정해야 합니다.

### 2. iPhone과 안경 연결하기

1. iPhone의 Meta AI 앱에서 안경 페어링을 완료합니다.
2. Meta AI 앱의 Developer Mode를 활성화합니다.
3. Xcode에서 iPhone 실기기를 선택해 Lumi를 실행합니다.
4. Lumi 온보딩의 안내에 따라 Meta AI에서 Lumi를 연결합니다.

### 3. 실행 전 확인

1. iPhone의 위치·마이크·알림 권한을 허용합니다. 위치는 날씨와 새 메모리의 장소 기록, 알림은 일정·타이머 알림에 사용합니다.
2. 설정의 **오디오 기기 상태**에서 현재 마이크·스피커 경로를 확인합니다.
3. 안경을 쓰지 않는 경우에도 음성 질문은 iPhone 또는 연결된 Bluetooth 기기로 시도할 수 있습니다.
4. 장면 설명, 카메라 번역, 사진이 필요한 장소·주차 기억은 안경을 연결한 상태에서 실행합니다.

## 배포 전 확인할 점

- `Secrets.xcconfig`은 `.gitignore`에 포함되어 있으며 **절대 커밋하지 않습니다.** 저장소에는 `Secrets.xcconfig.example`만 유지합니다.
- 현재처럼 앱에서 Gemini API 키를 직접 사용하는 방식은 개발·검증 용도입니다. 출시 버전에서는 키를 앱에 넣지 말고 인증된 서버에서 짧은 수명의 토큰을 발급하세요.
- 일정은 현재 Lumi 내부 일정과 iOS 로컬 알림을 사용합니다. 시스템 캘린더 동기화는 별도의 EventKit 권한·동기화 설계가 필요합니다.
- 안경의 물리 버튼 이벤트를 앱에서 직접 제어하는 범위는 Wearables SDK의 공개 기능과 Meta 승인 정책을 따라야 합니다.

## 문제 해결

| 현상 | 먼저 확인할 점 |
| --- | --- |
| 음성은 들리는데 입력이 안 됨 | 설정의 **오디오 기기 상태**에서 마이크 경로를 확인하고, iOS 마이크 권한을 허용합니다. |
| 장면 촬영 버튼이 동작하지 않음 | Ray-Ban Meta 연결 및 Meta AI의 Developer Mode 상태를 확인합니다. 카메라 기능은 iPhone 단독으로 실행할 수 없습니다. |
| 메모리에 장소나 거리 정보가 없음 | 저장 당시 위치 권한을 허용했는지 확인합니다. 기존 기록의 장소는 사후에 추정하지 않습니다. |
| 날씨 조회에 실패함 | iPhone 위치 권한, 네트워크 연결, `KMA_WEATHER_API_KEY` 설정을 확인합니다. |
| Gemini 요청 실패 | `Secrets.xcconfig`의 `GEMINI_API_KEY`와 선택한 모델 접근 권한을 확인합니다. |
| 알림이 오지 않음 | iOS 알림 권한과 집중 모드, 타이머·일정의 남은 시간을 확인합니다. |
