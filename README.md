# Lumi

> 보고, 묻고, 듣는 Ray-Ban Meta 개인 AI 비서

Lumi는 Ray-Ban Meta 안경과 iPhone을 연결해 음성·카메라·현재 위치를 일상적인 대화에 활용하는 개인 AI 비서입니다. 안경에 대고 질문하면 답을 듣고, 눈앞의 장면을 설명받고, 필요한 정보는 사용자 메모리와 일정으로 남길 수 있습니다.

현재 저장소는 실기기 연결과 핵심 경험을 검증하기 위한 iOS MVP입니다. Lumi는 Meta 또는 Ray-Ban의 공식 제품이나 제휴 서비스가 아닙니다.

## Lumi로 할 수 있는 일

| 기능 | 경험 |
| --- | --- |
| 음성 대화 | 안경 마이크로 자연스럽게 질문하고 안경 스피커로 답을 듣습니다. 대화는 세션별로 이어져 앞선 맥락을 참고합니다. |
| 장면 이해 | 안경 카메라로 사진 한 장을 촬영해 메뉴, 문서, 물건, 주변 장면을 설명받습니다. |
| 카메라 번역 | 안경 카메라로 촬영한 메뉴·문서 등의 읽을 수 있는 텍스트를 한국어로 번역합니다. |
| 사용자 메모리 | “기억해줘”, “메모해줘”, “기록해줘”처럼 명확히 요청한 내용만 요약해 저장합니다. |
| 장소 기억 | “여기 기억해줘”라고 말하면 위치·사진·메모를 함께 남겨 나중에 찾을 수 있습니다. |
| 주차 기억 | 현재 주차 위치를 요청하면 안경 사진과 위치를 함께 저장하며, 가장 최근 기록 하나만 유지합니다. |
| 일정과 리마인더 | 대화에서 약속 시각을 파악해 Lumi 일정으로 등록하고, 지정한 시간에 로컬 알림을 보냅니다. |
| 타이머 | “파스타 8분 타이머 맞춰줘”처럼 말하면 남은 시간을 보여주고 완료 알림을 보냅니다. 앱을 나가도 잠금 화면과 다이나믹 아일랜드에서 확인할 수 있습니다. |
| 날씨 | 현재 위치를 기준으로 기상청 단기예보를 조회해 오늘·내일·특정 시간대의 날씨를 안내합니다. |

## 이렇게 사용하세요

1. iPhone에서 Lumi를 열고 Ray-Ban Meta 안경을 연결합니다.
2. 메인 화면에서 안경 상태, 진행 중인 타이머, 다가오는 일정을 확인합니다.
3. AI 제어에서 장면 촬영, 음성 질문, 카메라 번역 또는 장소 저장을 바로 시작합니다.
4. 설정에서 **실행 전 확인**을 켜면, 일정·타이머·장소·주차·사용자 메모리 저장 전에 실행 여부를 확인합니다.
5. 답변은 음성으로 듣고, 대화와 사진은 해당 대화 세션에서 다시 확인합니다.
6. 정말 남겨야 할 정보는 “기억해줘”라고 말해 사용자 메모리에 저장합니다.

### 말해볼 수 있는 예시

- “지금 몇 시야?”
- “오늘 오후에 비가 와?”
- “내일은 어때?”
- “지금 보는 메뉴 설명해줘.”
- “이 내용 기억해줘. 다음 주에 디자인 검토하기.”
- “여기 기억해줘.”
- “여기 주차했어 기억해줘.”
- “지하 2층 F12에 주차한 곳 기록해줘.”
- “내일 3시에 팀 회의 기억해줘.”
- “파스타 8분 타이머 맞춰줘.”

## 앱 구성

### Lumi

안경 연결 상태와 모델 이미지를 중심으로, 현재 실행 중인 타이머·다가오는 일정을 한눈에 보여줍니다. 메인 화면은 정보를 과하게 카드로 나누지 않고 하나의 밝은 캔버스 위에 자연스럽게 배치합니다.

### 대화

새 세션을 만들기 전까지 한 대화를 계속 이어갑니다. 세션별 생성 시각과 대화 내용을 보관하며, 사진으로 질문한 경우 촬영 이미지도 대화 속에서 함께 확인할 수 있습니다.

### 사용자 메모리

일반, 일정, 주차, 장소 카테고리로 메모리를 관리합니다. 카테고리와 날짜 범위를 기준으로 쉽게 찾고, 직접 추가·수정·삭제하거나 한 번에 비울 수 있습니다. 주차 기억은 가장 최근 기록만 유지합니다.

### 주차 기억

주차 위치를 잊기 쉬운 상황을 위한 단일 최신 기록 기능입니다.

1. 안경을 착용한 상태에서 “여기 주차했어 기억해줘” 또는 “주차한 곳 기록해줘”라고 말합니다.
2. Lumi가 안경 카메라로 현재 장면을 촬영하고 iPhone의 현재 위치를 가져옵니다.
3. **사용자 메모리 → 주차 기억**에서 촬영 사진, 저장 시각, 주소 또는 좌표를 확인합니다.
4. `지도에서 열기`를 누르면 Apple 지도에서 저장 위치를 확인할 수 있습니다.

새 주차 기억을 저장하면 이전 주차 메모리와 사용자 메모리에 연결된 사진은 자동으로 제거되어, 사용자 메모리에는 최신 항목 하나만 남습니다. 음성 요청이 포함된 대화 세션 기록은 별도로 남을 수 있습니다. 주차 위치를 직접 수정하거나 삭제할 수도 있습니다. 위치 권한 또는 안경 카메라에 접근할 수 없으면 주차 기억을 완성할 수 없습니다.

### 일정

대화로 등록된 일정과 수동으로 만든 일정을 확인·삭제합니다. 알림 권한이 허용된 경우 iPhone 로컬 알림으로 알려드립니다.

### 설정

상단 설정에서 **실행 전 확인**을 켜거나 끌 수 있습니다. 기본값은 켜짐이며, 켜진 경우 Lumi는 아래 동작을 실행하기 전에 요약 내용을 보여주고 실행 여부를 묻습니다.

- 사용자 메모리 저장
- 장소·주차 기억 저장
- 일정 등록
- 타이머 시작

직접 입력 화면에서 저장하는 일정·메모리는 사용자가 이미 내용을 검토한 뒤 저장하므로, 별도 확인을 추가하지 않습니다.

### Live Activity 타이머

타이머를 시작하면 Lumi가 잠금 화면에 남은 시간을 표시합니다. 다이나믹 아일랜드를 지원하는 iPhone에서는 상단에도 축약된 카운트다운이 나타나며, 길게 누르면 타이머 이름과 제어 버튼을 확인할 수 있습니다.

- **일시정지 / 재개:** Live Activity의 버튼을 누르면 Lumi를 열어 타이머 상태를 반영합니다.
- **취소:** Live Activity 또는 앱 안의 취소 버튼으로 타이머와 예정된 알림을 함께 제거합니다.
- **여러 타이머:** 잠금 화면에는 여러 활동이 표시될 수 있지만, 다이나믹 아일랜드에는 iOS가 선택한 활동이 표시됩니다.

Live Activity 표시는 iOS 시스템 설정, 집중 모드, 기기 지원 여부에 따라 제한될 수 있습니다.

## 개인정보와 데이터

Lumi는 개인 정보가 필요한 순간을 가능한 한 분명하게 드러내는 것을 원칙으로 합니다.

- 대화 세션, 사용자 메모리, 일정, 타이머는 iPhone 앱의 로컬 저장소에 보관합니다.
- 장면 질문을 할 때만 촬영한 사진을 Gemini API에 보내 분석합니다. 해당 사진은 대화 기록 또는 장소 기억에 남길 수 있습니다.
- 장소·주차 기억을 위해 촬영한 사진과 위치 정보는 사용자 메모리에 로컬로 보관합니다. 주차 기억 사진은 Gemini 장면 분석 요청에 사용하지 않습니다.
- 음성 질문의 처리를 위해 녹음 데이터와 대화 맥락이 Gemini API 요청에 포함될 수 있습니다.
- 날씨 요청 시 현재 위치를 기상청 예보 격자로 변환해 조회합니다.
- 앱 설정에서 불필요한 사용자 메모리·일정·타이머를 삭제할 수 있습니다.

민감한 개인정보, 인증 정보, 타인의 얼굴이나 문서가 담긴 이미지는 충분히 확인한 뒤 사용하세요. 실제 서비스 출시 전에는 별도 개인정보 처리방침, 동의 흐름, 데이터 보존 정책 및 서버 보안 설계가 필요합니다.

알림은 iOS 집중 모드, 시스템 설정, 기기 상태에 따라 지연되거나 표시되지 않을 수 있습니다.

## 기술 구성

- **UI:** SwiftUI
- **웨어러블 연결:** Meta Wearables Device Access Toolkit (`MWDATCore`, `MWDATCamera`)
- **AI:** Gemini API
  - `gemini-3.1-flash-lite` — 대화, 의도 파악, 장면 분석
  - `gemini-3.1-flash-tts-preview` — 한국어 음성 답변 생성
- **날씨:** 기상청 단기예보 조회서비스
- **알림:** UserNotifications 로컬 알림
- **Live Activity:** ActivityKit · WidgetKit

## 시작하기

### 요구 사항

- Xcode에서 현재 프로젝트의 배포 대상인 iOS 26.5 이상을 실행할 수 있는 iPhone
- Ray-Ban Meta 안경 및 Meta AI 앱 연결
- Meta Wearables Developer Mode 설정
- Gemini API 키
- 기상청 공공데이터포털 단기예보 API 인증키

### 1. 비밀 설정 만들기

저장소 루트에서 예시 파일을 복사합니다.

```bash
cp Secrets.xcconfig.example Secrets.xcconfig
```

`Secrets.xcconfig`에 본인 값만 입력합니다.

```xcconfig
META_APP_ID = 0
META_CLIENT_TOKEN = YOUR_META_CLIENT_TOKEN
GEMINI_API_KEY = YOUR_GEMINI_API_KEY
KMA_WEATHER_API_KEY = YOUR_KMA_WEATHER_API_KEY
```

개발 모드에서는 `META_APP_ID`를 `0`으로 둘 수 있습니다. 실제 배포 환경에서는 Meta 앱 ID와 클라이언트 토큰을 올바르게 설정해야 합니다.

### 2. iPhone과 안경 연결하기

1. iPhone의 Meta AI 앱에서 안경 페어링을 완료합니다.
2. Meta AI 앱의 Developer Mode를 활성화합니다.
3. Xcode에서 iPhone 실기기를 선택해 Lumi를 실행합니다.
4. Lumi 온보딩의 안내에 따라 Meta AI에서 Lumi를 연결합니다.

## 배포 전 확인할 점

- `Secrets.xcconfig`은 `.gitignore`에 포함되어 있으며 **절대 커밋하지 않습니다.** 저장소에는 `Secrets.xcconfig.example`만 유지합니다.
- 현재처럼 앱에서 Gemini API 키를 직접 사용하는 방식은 개발·검증 용도입니다. 출시 버전에서는 키를 앱에 넣지 말고 인증된 서버에서 짧은 수명의 토큰을 발급하세요.
- 일정은 현재 Lumi 내부 일정과 iOS 로컬 알림을 사용합니다. 시스템 캘린더 동기화는 별도의 EventKit 권한·동기화 설계가 필요합니다.
- 안경의 물리 버튼 이벤트를 앱에서 직접 제어하는 범위는 Wearables SDK의 공개 기능과 Meta 승인 정책을 따라야 합니다.
